# TCS Automation

An extensible V&V test automation framework intended to automate structured Test Cases (TCS) across multiple application technologies and deployment environments.

## Target Environments

- Windows desktop applications
- Qt Widgets applications
- Qt QML / Qt Quick applications
- Embedded Qt / Qt QML applications running on target hardware

## Project Principles

- Test-case technology independence
- Deterministic and auditable execution
- Adapter-based architecture
- Requirement-to-test traceability
- Evidence-driven V&V reporting
- Incremental development with documented baselines
